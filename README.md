## 🛠 기술 스택

### Frontend
- **Vue.js 3.x** - 프로그레시브 JavaScript 프레임워크
- **Pinia** - Vue 공식 상태 관리 라이브러리
- **Vue Router** - 공식 라우팅 라이브러리
- **Axios** - HTTP 클라이언트
- **Vuetify** - 머티리얼 디자인 컴포넌트 프레임워크
- **Chart.js** - 데이터 시각화 라이브러리

### Backend & Services
- **Firebase** - Authentication, Firestore Database
- **CI/CD** - 자동화된 빌드 및 배포
